# Passages

This directory holds submitted passages — original writing offered for
consideration, judged against the bar in `CONTRIBUTING.md`: vocabulary used
masterfully, intentionally broad, in context.

The passage schema is not published yet, so a submission is prose: add it
here as plain text. It may be judged by people or by automated reviewers,
and it can be removed later by anyone with a one-line reason in the commit.
Removal is deliberately cheap, so the bar for accepting a passage can stay
generous.

Sourced excerpts from existing literature are a different thing, with their
own rules — see `CONTRIBUTING.md`.
