Open source

You can read, check and argue with everything here.

The code, the content pipeline and every book's records are public. This page explains the licences, and how to take part.

The code

The whole app lives in one repository: github.com/kihea/superb. That covers the reading app, the learning engine (Rust, compiled to WebAssembly), this website, and the pipelines that build the content. The licence is MIT with the Commons Clause. Read it, run it, change it and share your changes. Do not sell it as a service.

The books

All 1,478 books are public domain, kept in their own repository at superb-catalogue/library. Every book carries a provenance record: the source of the text, the edition and the licence. A stranger can check it without asking anyone.

The word data

Word meanings come from the English Wiktionary (via wiktextract, CC BY-SA 4.0), rhyme judging from CMUdict, and word associations from WordNet and the project's own corpus. The repository's data manifest names each source and its licence. No non-commercial or all-rights-reserved source enters a build.

How changes happen

Through ordinary GitHub issues and pull requests. Open an issue if a definition is wrong, a passage reads badly or a screen fails. Plain words are enough, and there is no template. The repository's CONTRIBUTING file covers running it locally.

What transparency means here

The app does not explain everything on every screen, because it aims for a minimal feel. But nothing is hidden. You can check every claim in the source: what Superb fetches, what it stores and what the engine learns from. The site's own build proves its network policy on every push.
